## 2. Kiến trúc chi tiết Phương án A — Luồng dữ liệu & Hợp đồng giao diện

```text
[1. Source Code + Graphify / LSP]
        │
        ▼ (0 LLM tokens · Python AST / Symbol Hash)
[2. Logic Node Registry Index (index.json)] ──► AST khớp nhưng dịch dòng? ──► Tự cập nhật span_binding (0 LLM, 0 finalize)
        │
        ▼ AST thay đổi hoặc Lazy Depth được kích hoạt (Dirty Set D)
[3. Agent TDQ chỉ đọc & sinh đúng D nodes (nodes/<node_id>.json)]
        │  - Giải thích tự nhiên + edge_cases + mini sub_flow (3–5 bước)
        │  - Gắn ref_node_id nếu dùng lại node sạch từ Registry
        ▼
[4. Archify Single-Layer Slice Renderer (Không Fork)]
        │  - Sinh SVG thuần <= 5 cột/lát cắt (đạt >= 6px desktop-readability)
        │  - Đóng băng slice theo render_slice_sha256
        ▼
[5. Hai chế độ xuất HTML phù hợp từng bề mặt]
        ├─► Master Portal (docs/architecture/index.html + slices/*.svg + nodes/*.json)
        │      1 shell duy nhất (<250KB), Lazy load qua HTTP/Tailscale (hoặc script bundle fallback file://)
        └─► Spec / Report (docs/tdq/reports/<slug>.html)
               Self-contained 1 file HTML, nhúng gọn node dictionary + SVG lát cắt (<= 4 tầng)
```

### Quy tắc UI tương tác 1 click trên mọi Node (thay thế Modal 1 tầng hiện tại)

1. **Không sửa SVG gốc:** Lớp vỏ TDQ lắng nghe sự kiện `click` / `Enter` ở container cha nhờ thuộc tính chuẩn `data-node-id` mà `staticSvg()` bảo toàn [`46c9823abe29`].
2. **Mở Ngăn xếp Chi tiết (Drill-Down Drawer / Portal View):**
   - **Thẻ Giải thích Tự nhiên (Natural Layer):** Đọc trong 5 giây (Tóm tắt việc node làm, đầu vào → đầu ra, *ghi cái gì vào đâu*, trường hợp lỗi).
   - **Mini Flowchart tương tác (`<= 5` bước):** Render ngay bên dưới nếu `LogicNode` có `sub_flow_slice_id` hoặc danh sách bước con. Bấm tiếp vào bất kỳ bước con nào để **đào sâu xuống tầng kế tiếp (`depth + 1`)**.
   - **Breadcrumb & Cycle Guard:** Hiển thị `Flow tổng > Nhập Login > Kiểm tra Remember > Chính sách HttpOnly Cookie > Xoay vòng JTI`. Nếu bước con trỏ ngược về `node_id` đã có trong `visited_stack`, UI hiển thị thẻ neo chu trình (`↺ Quay về "<label>" ở tầng k`) và cho phép nhảy ngược an toàn.
   - **Thẻ Nguồn & Chứng cứ (Evidence Tab):** Hiển thị tối đa `3` liên kết `path:line-end_line` thật kèm huy hiệu `committed` / `working-tree` hoặc `[Dự kiến / planned]` nếu đang ở Spec.
