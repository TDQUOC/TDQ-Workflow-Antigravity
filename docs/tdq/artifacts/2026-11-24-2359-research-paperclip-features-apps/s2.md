# Shard S2 — Control Plane Runtime, 6 BYO Agent ưu tiên, Bảo mật & Ngân sách (H2)

> Kết luận giả thuyết **H2:** **XÁC NHẬN (`Verified`)** — Cơ chế điều phối Heartbeat + 11 trạng thái lifecycle, Circuit Breaker (`automaticRunBrakes`), Budget Hard-Stop giao dịch khóa cứng, Secrets theo phiên bản/binding và MCP Tool Gateway (`Allowed / Ask first / Off` + Changed-Tool Quarantine) đều đã cài đặt rất chặt chẽ trong backend. Tuy nhiên phát hiện **2 rào cản thực tế quan trọng**: (1) `Google Antigravity` mới ở mức pending integration ẩn UI và bị khóa cứng `darwin-arm64` (chưa chạy native trên Windows); (2) ở chế độ `local_trusted` trên Windows, cơ chế chống agent truy cập ngầm quyền board qua loopback không hoạt động (chỉ hỗ trợ Linux/macOS).

## 1. Luồng Heartbeat & Bounded Run Recovery (`Verified`)

- **Hợp đồng Workspace không phụ thuộc Git remote (`packages/adapters/AUTHORING.md:8-58`):** Thư mục làm việc cục bộ (`local cwd` / worktree) là ranh giới duy nhất lưu trạng thái qua nhiều nhịp heartbeat; mọi adapter bị chặn tĩnh bởi `scripts/check-no-git-push.mjs` để không tự ý `git push`. Nếu sync-back workspace thất bại (`workspace_finalize=failed`), các task phụ thuộc bị khóa không wake.
- **Vòng đời Agent 11 trạng thái (`doc/AGENT-LIFECYCLE.md:38-89`):** `pending_approval` → `preparing` → `verifying` → `ready` → `pausing/paused/resuming` → `terminating/cleaning_up/terminated` / `rejected`. Tác vụ reconcile policy check xử lý theo lô 100 agent/phút, mọi thay đổi ngân sách/công ty cập nhật giữ nguyên tử.
- **Circuit Breaker chống lặp chết (`server/src/services/recovery/automatic-run-brake.ts:8-32`):** Trạng thái `closed` → `open` → `half_open`. Tự ngắt mạch nếu trong `10` phút có `>= 12` lượt tự động với `>= 80%` lỗi tiền khởi chạy, hoặc `5` lần provider từ chối liên tiếp; tự thử hé lại với `2` probe thành công và mở dần qua `6` nấc tốc độ.

## 3. Bảo mật, Phân quyền, MCP Tool Gateway & Ngân sách (`Verified`)

1. **MCP Tool Gateway 4 lớp (`doc/MCP-ACCESS-GOVERNANCE.md:27-62,213-306`, `server/src/services/tool-access-policy.ts:1-90`):**
   - Phân tách rõ **Profile** (quyết định agent *nhìn thấy* tool nào theo thứ tự `issue > routine > agent > project > company`) và **Policy** (`allow`, `block`, `require_approval`, `rate_limit`, `trust_rule`; nguyên tắc bất biến **Deny always beats allow**).
   - **Changed-tool quarantine (`line 221`):** Upstream MCP âm thầm thêm tool `write`/`destructive` sẽ tự động bị đưa vào diện cách ly `quarantined` cho tới khi người duyệt mở khóa.
   - **Lỗ hổng được công bố minh bạch (`line 148`):** Paperclip không chặn được nếu tiến trình tự chạy ngoài sandbox tự gọi thẳng upstream MCP server bằng cấu hình sửa tay (chỉ kiểm soát được call đi qua gateway).
2. **Secrets per-agent & Redaction (`server/src/services/secrets.ts:1-90`, `packages/db/src/schema/index.ts:164-173`):**
   - Lưu bí mật theo phiên bản (`companySecretVersions`), trỏ binding chính xác tới từng agent/project/environment, ghi log truy cập `secretAccessEvents` và che giấu bí mật khỏi run log (`run-secret-redaction.ts`).
3. **Chế độ Deployment & Cảnh báo Windows (`doc/DEPLOYMENT-MODES.md:62-100`):**
   - Hỗ trợ `local_trusted` (không login, loopback), `authenticated + private` (LAN/Tailscale) và `authenticated + public`.
   - **Cảnh báo bảo mật nghiêm trọng trên Windows (`line 86`):** Ở chế độ `local_trusted`, cơ chế kiểm tra cây tiến trình nhằm chặn tiến trình con của agent tự nhận quyền board trên loopback **chỉ hoạt động trên Linux/macOS**; Windows vẫn giữ hành vi cũ (agent chạy nội bộ dễ đụng loopback nếu không bật `authenticated`).
4. **Prompt Injection Prevention (`server/src/services/prompt-injection-prevention.ts:23-70`):**
   - Lớp lọc độc lập kiểm tra nội dung đầu vào từ gateway/provider bên ngoài trước khi agent tiêu thụ (opt-in theo cấu hình công ty qua OpenRouter connection).
5. **Budget Hard-Stop (`server/src/services/budgets.ts:102,365-415`):**
   - Đo chi phí chuẩn xác tới 7 chữ số thập phân (`numeric(24,7)`), khi chạm `budgetMonthlyCents` phát ngay trạng thái `hard_stop`, khóa row trong DB (`for("update")`), đặt `pauseReason: "budget"` ở cả Agent/Project/Company và đẩy lệnh hủy run đang chạy vào `DELIVERY_QUEUES.budgetEnforcement`.
