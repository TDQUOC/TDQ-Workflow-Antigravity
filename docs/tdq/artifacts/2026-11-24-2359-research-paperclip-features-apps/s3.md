# Shard S3 — Hệ sinh thái mở rộng & Đánh giá triển khai thực chiến (H3)

> Kết luận giả thuyết **H3:** **XÁC NHẬN CÓ ĐIỀU KIỆN (`Verified` về kiến trúc / `Single-source` & `Inferred` về vận hành Windows)** — Hệ sinh thái mở rộng của Paperclip rất bài bản về mặt SDK và đóng gói: `@paperclipai/plugin-sdk` `1.0.0` có đủ `protocol`, `ui`, `testing`, `dev-server`; `9` sandbox provider cloud; `skills-catalog` (`5` bundled + `6` optional), `teams-catalog` (`3` bundled + `2` optional), `9` built-in skill và `@paperclipai/paperclip-eval-kernel`. Tuy nhiên hệ sinh thái này **ưu tiên Linux / macOS / WSL2 / Docker**: trên Windows thuần không chạy được `install.sh` trực tiếp, thiếu bảo vệ process-tree ở `local_trusted`, và Plugin UI hiện chưa có iframe sandbox.

## 2. Đánh giá cài đặt & vận hành thực chiến (`mặt 1c`)

1. **Yêu cầu nền tảng (`Verified`):** Phải có **Node.js `>= 24.11.0`**, khi chạy từ mã nguồn cần **`pnpm@9.15.4`**; dữ liệu dùng PostgreSQL nhúng (nhanh cho single-node) hoặc Postgres ngoài + Docker Compose (`docker/docker-compose.yml`).
2. **Linux / macOS / WSL2 / Docker so với Windows thuần (`Verified` kiến trúc / `Inferred` ma sát runtime):**
   - `install.sh` hỗ trợ chính thức **macOS, Linux hoặc WSL2** (`doc/INSTALLING.md:10`); ảnh Docker chuẩn (`doc/DOCKER.md:10-46`) build sẵn `server/dist-runtime/index.mjs` cùng `Claude`, `Codex`, `OpenCode` CLIs trên Linux AMD64/ARM64.
   - Trên **Windows thuần**: CLI `paperclipai doctor` và `onboard` vẫn chạy qua Node nhưng phát sinh 3 bất lợi: (a) thiếu `install.sh` trực tiếp (nên chạy trong Docker hoặc WSL2); (b) `local_trusted` không cách ly tiến trình con trên loopback (`doc/DEPLOYMENT-MODES.md:86`); (c) nhánh `Paperclip Runner` + `Antigravity` / một số sandbox cloud nhắm Linux/macOS (`doc/runner-internals.md:87-118`).
3. **Chi phí vận hành & Rủi ro thực chiến (`Single-source` / `Inferred`):**
   - **Chi phí token:** Mỗi nhịp **heartbeat** đều bơm ngữ cảnh task, mục tiêu công ty/dự án, comment mới và skill `paperclip`; nếu để nhiều agent poll theo cron không có việc hoặc không cài ngân sách trần, chi phí LLM sẽ tăng nhanh theo số agent (`README.md:128,201`, `skills/paperclip/SKILL.md:22-24`). Paperclip giảm rủi ro này bằng `budgetMonthlyCents` + `hard_stop` + `automaticRunBrakes`.
   - **Bẫy vận hành shell injection CLI (`Verified`):** `skills/paperclip/SKILL.md:28` cảnh báo rõ **không dùng `pnpm paperclipai`** khi đối số chứa văn bản untrusted (issue/comment) vì `pnpm` bọc qua `/bin/sh` dễ bị inject; bắt buộc dùng `npx paperclipai` hoặc `node cli/...`.
   - **Rủi ro phụ thuộc patch nặng (`Verified`):** `package.json:112-138` vá thẳng 11 gói (`embedded-postgres`, `acpx`, `@chat-adapter/*`), nên việc nâng cấp tay hoặc fork dự án sẽ tốn công duy trì đồng bộ bản vá.
