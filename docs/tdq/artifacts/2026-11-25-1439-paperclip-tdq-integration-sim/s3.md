## 1. Bảo mật MCP Tool Gateway & Ngân sách (`Verified`)

1. **Khoảng trống hiện tại ở TDQ:**
   - `hooks/scripts/agy_pretooluse_gate.py:1-56` mới chặn cứng `2` luật shell (`nhánh cấm` và `ghi thẳng docs/tdq/state.json`), chưa có lớp phân quyền công cụ MCP theo vai trò hay phát hiện tool `write`/`destructive` mới xuất hiện từ MCP server ngoài (`bddb62961afe` vs `3e7aa4dd449b`).
   - `scripts/token_budget.py:1-49` chỉ là khóa SHA-256 kiểm độ dài file `.md` (`TRAN_TOKEN = 3500`) trong CI; TDQ chưa có bộ đếm trần chi tiêu/chi phí runtime kiểu `hard_stop` để phanh khẩn cấp khi một wave subagent chạy lặp bất thường (`bddb62961afe`, `968ec32977a4`).
2. **Phần chuyển thể gọn từ Paperclip (`Pattern-Native`):**
   - **MCP Policy Registry + Changed-Tool Quarantine (`6d4c00eed673`):** Tạo bảng chính sách tĩnh dạng JSON phân tách quyền theo vai trò/pha (`allow` / `ask` / `deny`, `deny` luôn thắng `allow`), kèm băm SHA-256 danh sách chữ ký tool MCP (`mcp-tool-baseline.json`). Khi tool mới mang nhãn ghi/phá hủy xuất hiện, tự động đánh dấu `quarantined` và chặn gọi cho tới khi người dùng duyệt.
   - **Budget Watchdog / Soft & Hard Stop (`968ec32977a4`):** Gắn thêm bộ đếm ngân sách lượt gọi/token/chi phí ước tính vào `tdq_timing.py` / `tdq_state.py`: cảnh báo ở ngưỡng `80%` và đặt cờ pause ở ngưỡng `100%` (`hard_stop`) ngay trước khi gọi tiếp wave subagent mới.

## 2. Đánh đổi `Pattern-Native` vs `Hybrid Bridge` trên Windows + Antigravity (`Verified`)

| Tiêu chí đánh giá (`2a+c`) | Hướng 1: `Pattern-Native` (Python stdlib + Git vào lõi TDQ) | Hướng 2: `Hybrid Bridge` (Nối `TDQ` ↔ `Paperclip Server` Docker/WSL2) | Phán quyết cho từng pha |
|---|---|---|---|
| **1. Bảo toàn 100% hành vi TDQ (`5b`)** | Mọi hook `agy_pretooluse_gate`, `agy_stop_gate`, `edit_gate`, `tdq_state.py` vẫn giữ quyền tối thượng một cửa | Hai state machine (`state.json` vs Postgres `issues`) dễ lệch trạng thái nếu sync trễ; heartbeat poll có nguy cơ phát lặp lệnh (`320ec188d2a9`) | `Pattern-Native` thắng tuyệt đối ở lõi |
| **2. Không ép DB server trên Windows** | **0 dependency mới** — chạy thuần Python 3 + Node sẵn có của `tdq-workflow-agy` (`5b0d134135a8`) | Bắt buộc Node `>= 24.11`, `pnpm@9.15.4`, PostgreSQL + Docker/WSL2; kéo theo `11` bản vá phụ thuộc (`a22d6a034353`) | `Pattern-Native` đạt; `Hybrid Bridge` **TRƯỢT** làm lõi (chỉ hợp làm add-on tùy chọn `P2`) |
| **3. Tương thích Windows + Antigravity** | `tdq-workflow-agy` chạy native trên Windows (`5b0d134135a8`) | Adapter Antigravity của Paperclip bị khóa cứng `darwin-arm64` (`342b3fd669d4`); chế độ `local_trusted` mất bảo vệ process-tree trên Windows (`e79c1da5f2ab`) | `Pattern-Native` đạt hoàn toàn trên Windows |
| **4. Rủi ro UI mở rộng & Add-on `P2`** | Giao diện qua Archify HTML tĩnh, không nhúng JS ngoài | Plugin UI của Paperclip chạy dạng `same-origin JS` không sandbox iframe và chưa sẵn sàng cloud (`642dbc026abe`); chỉ nên đẩy "task nặng coding" sang TDQ qua Bridge tách rời | Giữ `Bridge` làm **P2 Opt-in Add-on** (tắt mặc định, không đem `same-origin UI` về TDQ) |
